ANSYS Unified MCP 現行架構拓撲

精準呈現 FastMCP 雙軌別名層、SessionRegistry 中樞、gRPC 埠號拓撲 (Port 10000/50051) 與求解器批次子程序通道。

GEOMETRY DISPATCH

SpaceClaim: 雙軌通道特徵

SpaceClaim 依操作場景精準分流至兩種不同架構：

  • PyAnsys Geometry：確實走 gRPC 通道（預設埠號 50051），提供 Python 直驅 3D 建模。
  • Workbench ACT 模式：在 Workbench 專案環境下則透過檔案 IPC 橋接傳遞 IronPython 腳本。

EXPLICIT SOLVER

LS-DYNA: GUI vs. 求解核心

LS-DYNA 在架構上分為「前處理介面」與「數值求解器」：

  • Mechanical GUI 視窗：作為前處理時，可走 Mechanical 的 gRPC 通道 (Port 10001) 設定邊界。
  • 求解器核心 (lsdyna.exe)：數值計算本身非 gRPC，而是以子程序命令列 (i=run.k) 批次驅動並由 Sentinel 監控。

SESSION CORE

SessionRegistry 全域會話池

集中式管理所有即時連線實例與通訊埠號：

  • Port 10000+：Mechanical (結構 / 模態 / 熱-結構耦合)。
  • Port 50051+：SpaceClaim / Discovery (PyAnsys Geometry)。
  • Port Scan：自動偵測 Windows 本機正在執行的 CAE 進程並掛載。
