# LS-DYNA 質量縮放判讀

質量縮放會改變模型慣性；是否可接受取決於分析目的、增加質量的空間分布及關注量。必須保留未縮放基準或敏感度對照，不能只看總質量百分比。

## 必要檢查

- 記錄 solver release、`*CONTROL_TIMESTEP` 欄位、縮放模式、時間步長歷程、初始/新增質量及新增質量位置。
- 檢查縮放是否集中在接觸區、主要承載路徑或高加速度區，並比較關注量（如峰值力、位移、加速度、塑性應變）對縮放的敏感度。
- 依目標 release 的 LS-DYNA User's Guide 解讀 `DT2MS` 符號與選項；不能把不同版本/卡片模式的語義混用。
- 如無法取得新增質量分布或關注量對照，將可信度標示為 `unverified`，不得宣稱通用通過。

## 官方來源與適用條件

本地 `D:\ansys-docs-local\Documentation_md\LS-DYNA_Implicit_Analysis_Guide.md`（2026 R1）§12.1 說明 conventional mass scaling 的 `DT2MS < 0` 慣例，並指出可接受新增質量高度依問題而定：瞬態動力案例可將約 5–10% 作為適度示例，而較低動態性的成形案例可能容許更高比例。該內容是示例與上下文，不能變成所有分析的門檻；載入本手冊前須確認目標 solver release/分析類型一致。Selective mass scaling 的卡片欄位依該版本指南確認，不由 DT2MS 單一正負號推斷。

## 專案經驗值

本專案舊版曾使用 1/2/5% 增量與 0.1% 質心位移作警戒值。這些數值未證明為跨案例官方規範，故只能在同類落摔模型作初始篩查，並標記 `project heuristic`；不可單憑超限阻止所有分析，也不可單憑低於門檻判定結果有效。每次使用需記錄模型、材料、網格、縮放分布與對照結果。

避免以單一 `DT2MS` 數值追求速度。若時間步長由局部退化網格控制，先定位元素並評估幾何/網格修正；改動後仍須確認同一物理問題與關注量。
