## 一、S-N 曲線疲勞分析標準流程概念

1. **材料疲勞數據取得**：S-N 曲線（Stress-Life Curve）描述交變應力幅值（Alternating Stress, $\sigma_a$）與對應疲勞壽命（Cycles to Failure, $N$）之關係，通常由標準疲勞試驗（旋轉彎曲、軸向拉壓等）取得，或引用材料手冊（如 ASME BPVC Section VIII Division 2 Annex 3-F 之標準曲線）。
2. **載荷歷程定義**：需確認結構承受之載荷為定值反覆（Constant Amplitude）或變動幅值（Variable Amplitude）。變動幅值須先以雨流計數法（Rain-flow Counting）等方法分解為一系列等效循環區塊，才能逐一代入 S-N 曲線查壽命。
3. **平均應力修正**：實際結構的應力循環多非完全反向對稱（Fully Reversed, $R=-1$），須透過平均應力修正理論將非對稱循環等效轉換為對稱循環下的等效交變應力，再查 S-N 曲線（詳見第二節）。
4. **單次循環損傷度計算**：每個應力區塊的損傷度為 $d_i = n_i / N_i$，其中 $n_i$ 為該應力水準下實際發生的循環數，$N_i$ 為 S-N 曲線查得的該應力水準下的允許壽命。
5. **累積損傷度求和**：依 Miner's Rule 將所有應力區塊的損傷度線性加總，判斷是否達到臨界損傷值（詳見第三節）。
6. **結果判讀**：疲勞分析最終輸出通常包含壽命（Life，以循環數或等效使用年限表示）、累積損傷度（Damage）與疲勞安全係數（Fatigue Safety Factor）三項指標，三者可互相換算但各自適用不同的工程溝通場景（如壽命數字給客戶，安全係數給設計餘裕判斷）。

## 二、平均應力修正理論 (Mean Stress Correction)

| 理論 | 修正公式概念 | 力學假設與適用場景 |
|---|---|---|
| **Goodman** | 等效交變應力隨平均應力 $\sigma_m$ 線性遞減，修正基準為材料極限抗拉強度 $\sigma_u$ | 假設材料在平均應力接近極限強度時即喪失疲勞承載能力；為工程上最常用、較不保守的修正方式，廣泛用於延性金屬一般疲勞評估 |
| **Soderberg** | 修正基準改為材料降伏強度 $\sigma_y$（而非極限強度 $\sigma_u$） | 比 Goodman 更保守，因降伏強度低於極限強度；適用於要求結構在任何疲勞循環下均不產生塑性變形的高安全餘裕設計場景 |
| **Gerber** | 以拋物線（二次方）關係描述平均應力對疲勞強度的影響，而非線性遞減 | 較貼近部分延性金屬實驗數據在中等平均應力範圍的實際表現，但在高平均應力區域可能過度樂觀，須配合安全係數使用 |

**選用原則**：三種理論的保守程度排序為 **Soderberg（最保守） > Goodman > Gerber（最不保守）**。安全關鍵結構建議優先採用 Goodman 或 Soderberg；若材料具充分實驗驗證數據支持 Gerber 曲線形狀，可用於非安全關鍵零件以避免過度設計。

## 三、Miner's Rule 累積損傷法則

### 1. 理論假設
- **線性累積與加總性**：每次應力循環造成的損傷為常數 $1/N_i$，所有循環的損傷可直接線性加總，總損傷 $D = \sum (n_i / N_i)$。
- **負載順序無關性**：假設應力施加順序不影響損傷累積速率，先高應力後低應力與先低應力後高應力的損傷效果視為相同。
- **臨界損傷判據**：當累積損傷 $D$ 達到 1（或工程上設定更嚴格的臨界值）時，判定發生疲勞破壞。

### 2. 工程應用限制
- **忽略負載順序效應**：實際材料中「先高應力後低應力」會因前期微裂紋加速後續擴展，導致實際失效發生於 $D < 1$；「低應力預加載」則可能因加工硬化或殘餘壓應力使臨界 $D > 1$。
- **忽略過載與應力交互作用**：無法捕捉峰值過載造成的塑性區發展或裂紋閉合滯後現象。
- **低於疲勞極限應力的累積可能被低估**：傳統 Miner's Rule 認定低於材料疲勞極限的應力循環不造成損傷（$n_i/N_i = 0$），但若結構已因先前高負載萌生微裂紋，微小應力仍可能推動裂紋擴展。
- **工程對策**：安全關鍵結構建議在 $D=1$ 之前設定更嚴格的臨界損傷值（如 $D \le 0.5 \sim 0.8$）作為設計餘裕，並搭配定期檢測排除順序效應誤差累積的風險。

### 3. 在 ANSYS Mechanical 中的實作定位
Fatigue Tool 的 Damage（累積損傷）結果物件即依據 Miner's Rule 線性加總概念輸出；若分析涉及變動幅值載荷歷程，需先完成雨流計數分解再逐一代入求解。**具體的 Fatigue Tool 操作介面與結果物件 API 簽名待 api_search 查證**。

## 四、常見誤用提醒

> [!CAUTION]
> 1. **嚴禁未做平均應力修正直接套用完全反向對稱的 S-N 曲線**：實際結構載荷多含非零平均應力，若忽略修正會高估疲勞壽命，造成過早疲勞斷裂風險。
> 2. **嚴禁對經歷顯著負載順序效應（如先高應力衝擊後長期低應力運轉）的結構單純套用 Miner's Rule 而不設計餘裕**：線性累積假設在此類工況下可能顯著低估實際損傷速率。
> 3. **嚴禁套用未經驗證來源的 ANSYS Fatigue Tool API 呼叫**：Loading Type 選項、S-N 曲線匯入格式等細節尚未經 api_search 工具查證，實作前務必先行查證存在性與正確呼叫方式。
