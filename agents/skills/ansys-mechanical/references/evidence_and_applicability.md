# 工程規則的適用範圍與證據等級

將規則標為必要條件、官方建議或專案經驗值。必要條件描述模型能否建立/求解/讀取；官方建議須附產品版本、分析類型、材料/單元條件和手冊位置；專案經驗值須保留案例背景並可被校準，不可寫成跨案例硬門檻。

網格指標應同時記錄指標名稱與定義、元素類型/階次、分析類型、求解器限制及最差區域。負體積、求解器明確拒絕或無法形成有效網格屬硬錯誤；其餘品質值除非目標版本文件明確規定，不可單獨作阻斷條件。網格獨立性須對固定關注量作系統性細化比較。

薄壁建模方法依厚度方向單元型式、物理行為和目標量決定；不得要求所有薄壁都用同一元素或固定層數。支承需移除非物理剛體模態並符合真實邊界，不能無條件要求固定全部六個自由度。

結果可信度需指出其來源：`synthetic`、`estimated`、`solver_result` 或 `unverified`。真實 solver 結果需有可核對的 solver 狀態、日誌及輸出檔；工程有效性另由物理案例檢查。
