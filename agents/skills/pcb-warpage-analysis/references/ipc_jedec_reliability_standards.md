# IPC-9701A / IPC-7095 焊點可靠度判定準則

> 來源筆記本：*IPC-9701A SMT Attachment Reliability Test Methods*、*Reliability Engineering Principles*（Google NotebookLM）。
> 本文為技術要點改寫整理，非逐字搬運，供 PCB 熱翹曲分析後續銜接焊點可靠度評估時參考。數值已標註出處章節方向，實際設計門檻仍須以客戶/產品類別協議值為準。

---

## 一、IPC-9701A 熱循環測試條件（無鉛 / SAC 焊點適用）

### 1. 溫度區間（5 種標準條件）
| 條件 | 溫度範圍 | 備註 |
| :--- | :--- | :--- |
| TC1 | 0°C ~ +100°C | **首選參考條件**，業界最廣泛接受 |
| TC2 | -25°C ~ +100°C | |
| TC3 | -40°C ~ +125°C | 高階應用，PTH 可靠度風險較高 |
| TC4 | -55°C ~ +125°C | |
| TC5 | -55°C ~ +100°C | |

- Bi-Sn 低溫無鉛合金強制採 TC1；若搭配 Sn-Pb 鍍層元件則建議 -25°C ~ +75°C。
- 升降溫速率上限：**< 20°C/min**（避免誘發熱衝擊而非真實熱疲勞機制），量測取線性段 10%~90% 區間。
- 停留時間（dwell）：標準基礎為高低溫各 ≥ 10 分鐘（公差 +0/-10°C）。SAC 合金另有兩種附錄補充條件：
  - **D10（10 分鐘 dwell）**：單位時間誘發最大應變能，適合無鉛焊點獨立壽命評估，不宜直接與傳統 SnPb 比較。
  - **D30+（30~60 分鐘 dwell）**：誘發較充分的蠕變損傷，供無鉛與傳統焊點比較基準。

### 2. 循環次數與終止條件
NTC-A ~ NTC-E 對應 200 / 500 / 1,000 / 3,000 / 6,000 次循環，**TC1 + NTC-E（6,000 次）為業界首選參考組合**。測試在「達到設定循環數」或「累積失效率達 50%（首選 63.2%）」兩者先到者即終止。

### 3. 樣品與板材規範
- 標準最少 33 個元件（32 用於熱循環電測，1 個做 Time-zero 金相切片；若需評估重工則加 10 個）。
- 參考板厚 2.35 mm。
- 無鉛測試強制使用 OSP 或浸銀表面處理，**禁止 Sn-Pb HASL**。

### 4. 失效判定（電性監測）
- **事件檢測器法（首選）**：daisy-chain 電阻瞬間升至 ≥ 1000 Ω、持續 ≤ 1 µs 的斷路事件，且在後續 10% 循環內再出現 ≥ 9 次確認事件，判定為失效。
- **資料記錄器法**：連續最多 5 次掃描（間隔 ≤ 1 分鐘）內電阻較初始值上升 ≥ 20%，判定失效。
- 嚴禁人工手測作為唯一監控手段。

### 5. 可靠度統計與驗收
- 採用 **2 參數 Weibull 分布**：特徵壽命 η（N 63.2%）與形狀參數 β（磨損型失效 β > 1）。
- **IPC-9701A 本身不設統一的「必須通過幾次循環」判定值**，驗收標準需買賣雙方依產品應用類別（IPC-9701A Table 3-1，共 9 類）與設計壽命，協議可接受累積失效機率（如壽命終期 < 1% 或 < 0.1%），再透過加速因子換算成循環次數門檻。
- 若測試達到目標循環數仍為 Zero Failure，規範**強制要求**抽樣至少 3 個元件做金相切片 + 染色滲透（dye-and-pry）確認無潛藏裂紋，避免因電路設計或測試治具誤判。

## 二、BGA/CSP 焊點與 Underfill / Mold Compound 界面裂解判準

### 1. 關鍵結論：規範未定義 FEA 數值門檻
IPC-9701A、IPC-7095 屬於**實體測試方法規範**，並未對有限元素分析結果（Von Mises 應力、臨界應變、角隅應力奇異性強度）給出任何固定容許值或計算公式。這些屬於 CAE 模擬與材料力學建模範疇，留給設計團隊依封裝結構自行建立準則。**若需要具體的 FEA 判定門檻公式，請視為「待 api_search / 待進一步文獻查證」，不可憑此文件直接引用為設計標準。**

### 2. 規範中唯一的量化數值：板級機械應變極限
IPC-7095 引用 IPC/JEDEC-9704 板級應變量測規範（BGA 角隅三軸應變規）：
- Sn-Pb 組裝：應變極限 600 µε（主應變或對角應變）
- 無鉛（Pb-free）組裝：應變極限 450 µε（因無鉛焊點較硬、延展性較差）
- 最大允許應變速率：30,000 µε/s
- 典型損傷判定：金相切片後焊點無可見裂紋即視為通過

此數值源自板彎/ICT 治具機械應力測試情境，與熱翹曲模擬的熱應力場不同物理機制，套用時需評估適用性，不可直接等同於熱循環 FEA 的應變容許值。

### 3. 物理失效機制（供模擬結果判讀參考）
- 焊點疲勞起始於位錯運動形成滑移帶 → 晶界處微孔洞成核（約消耗 25% 疲勞壽命時出現）→ 微孔洞聚合成微裂紋（約 40% 疲勞壽命時）→ 裂紋擴展貫通。
- SnPb 焊點：熱循環下應變集中區發生晶粒粗化（grain coarsening），粗化晶粒較軟，助長裂紋擴展。
- SAC 無鉛焊點：高熱機應力區發生再結晶（recrystallization），再結晶晶粒更小且易發生晶界滑移與蠕變變形，裂紋沿此再結晶區擴展。
- 理想 CTE 失配下最大剪應力面約在 45° 方向，可作為模擬後處理時裂紋路徑合理性的定性檢查依據（非定量判據）。

### 4. 結構設計層面的應力集中緩解（非 FEA 判據，為設計準則）
- **NSMD（Non-Solder-Mask Defined）焊盤**優於 SMD 焊盤：SMD 焊盤因防焊漆尖角造成應力集中，是裂紋常見起始點；改用 NSMD 可提升疲勞壽命約 1.25~3 倍（規範引述的實務經驗範圍，非保證值）。
- BGA 角隅與晶片陰影（die shadow）正下方焊點因 CTE 失配最大，是熱循環失效高風險區，模擬時應優先關注此區域的應力/應變集中。
- Underfill、Corner Bond、Edge Bond 等聚合物補強可顯著分散角隅焊點應力，提升抗衝擊/抗跌落與熱循環壽命；全面毛細流動 underfill、部分流動 underfill、角隅點膠為三種常見補強方式，但規範未給出對應的量化應力降低比例可直接套用於模擬驗收。

### 5. 疲勞壽命預測模型（存在但規範未提供完整公式）
IPC-9701A 附錄 B 提及無鉛焊點熱疲勞壽命預測存在多種模型（Darveaux、Anand、Clech、Syed 等），分類為解析模型、一維應變能模型、有限元素應變能模型三類，但：
- 規範本身**不提供這些模型的完整計算公式或參數表**，僅說明其存在與分類。
- 經查詢 Reliability Engineering Principles 筆記本，亦未包含 Darveaux 模型、Coffin-Manson/Engelmaier 模型公式或 FEA 應變能密度體積平均法的具體操作程序。
- **結論：若分析流程需要以 FEA 等效塑性應變或應變能密度推算疲勞循環數，公式與係數需另行查證權威文獻（如 Darveaux 原始論文），本技能目前不提供，待 api_search 查證。**

## 三、與本技能既有流程的銜接建議

1. 本技能的 3-2-1 靜定熱應力求解流程輸出為 Z 軸翹曲變形與板級應力分布，若後續需評估焊點熱疲勞壽命，需額外建立子模型（Submodeling，可參考 `ansys-submodeling-dpf` 技能）擷取焊點局部應力/應變場，再套用上述疲勞模型（需另行查證）。
2. 若模擬中需設定 Underfill / Mold Compound 材料屬性為黏彈性而非線彈性，材料模型選型與 Prony series 設定參考 `ansys-mechanical/references/hyperelastic_viscoelastic_materials.md`。
3. IPC-9701A 板級應變極限（450/600 µε）可作為模擬結果的量級合理性交叉檢查（非 FEA 驗收判據），例如模擬輸出之板彎曲應變若遠超此量級，應優先檢查邊界條件或網格是否異常，而非直接套用為焊點裂解門檻。
