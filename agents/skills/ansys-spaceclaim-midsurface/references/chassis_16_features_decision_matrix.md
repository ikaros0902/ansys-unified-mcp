# 伺服器機殼 16 大特徵抽中面決策矩陣與底層機制手冊

本手冊針對伺服器整機機殼（1U/2U/4U Server Chassis、HDD Cage、Fan Wall、Air Baffle）在 SpaceClaim 中進行抽中面時，解構原生 `Midsurface` 與 `Combine` 失敗之內核根因，並定義 **16 大典型製造與組裝特徵** 的量化識別訊號與 **4 階段自動化處置管線（Stage A ~ D）**。

---

## 一、底層幾何內核機制剖析

### 1. 原生 `Midsurface` API 判斷鏈與四大死穴
原生指令（`Midsurface.AddMatchingFacePairs`）依序執行：面片面積排序 $\rightarrow$ 中心法向平行檢驗（$|\vec{n}_1 \cdot \vec{n}_2| > 0.99$） $\rightarrow$ 法向投影距離 $0 < d \le t_{\max}$ $\rightarrow$ 相切鏈（`GetTangentChain`）一對一配對 $\rightarrow$ 向內 Offset $d/2$ 並延伸求交。
- **死穴 1（微小拔模角拒絕）**：沖壓回彈或壓鑄拔模角只要 $\ge 0.5^\circ$，法向點積低於門檻，直接判定非對向薄板。
- **死穴 2（單側不對稱特徵破洞）**：底板一側平整，另一側有壓鉚螺柱、盲孔或加強肋，兩側面積與相切鏈失衡，導致局部漏抽開天窗。
- **死穴 3（曲率半徑自相交）**：沖壓凸點（Dimple）或壓筋收尾處的內圓角半徑 $R < t/2$，向內偏移時曲率中心反轉，產生自相交尖刺。
- **死穴 4（多向包角延伸無解）**：三折邊交會角含止裂槽（Bend Relief），延伸求交無法形成封閉迴路，導致 `Execute()` 失敗。

### 2. 面體 `Combine` 布林合併失敗的三大根因
- **近共面容差混淆（Near-Coplanar Ambiguity）**：兩面片邊界微觀高差 $10^{-6}\text{ mm}$，ACIS 求交器無法判定穿透或相離而拋出例外。
- **切線相交（Tangential Intersection）**：圓角面與平面相切相接，法向叉積為零，無法收斂交線。
- **T 型接頭非流形衝突（Non-Manifold Edge）**：加強肋或限位舌片垂直立於底板（1 條邊連接 3 個面），違反標準流形布林限制。
- **工程鐵律**：**嚴禁對中面片調用硬布林 `Combine`，一律改用帶容差（$\tau = 0.1 \cdot t$）之 `SharePrep` (`StitchBodies = True`)**。

## 三、為何「主面複製 + 法向剛體平移 `Move` $t/2$」優於傳統曲面 `Offset`？

1. **面內孔洞零失真**：
   - 傳統 3D 表面 `Offset` 會沿孔壁與圓角法向膨脹，導致斜孔縮放、葫蘆孔尖角自相交。
   - **「複製單側主壁面 + 沿該面法向剛體 `Move` $t/2$」**：本質是純粹的歐氏剛體平移（Rigid Body Translation），面內所有圓孔、葫蘆孔、方槽的尺寸與幾何形狀 **100% 原封不動**。
2. **轉角自動消圓角直交**：
   - 略過折彎處的過渡圓角面，僅將相鄰兩主壁面各自向內平移 $t/2$ 後，透過邊界延伸求交（`Extend` / `SharePrep.StitchBodies`），兩平面直接在轉角交會為一條乾淨的 90° 結構折線，徹底消滅折彎處的狹長碎面。
