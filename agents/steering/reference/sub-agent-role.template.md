# Sub_Agent_Role 定義樣板

> 用途：定義一個 Loop 中各 Sub_Agent_Role 的分工，記錄其角色名稱、職責範圍、輸入/輸出、存取權限（唯讀/可寫）與製造者或檢查者分類，供分派任務與控管存取範圍時追溯。
> 建議存放位置：專案內 Loop 設計文件旁（例如 `loops/<loop-name>/sub-agent-roles.md`）。
> 填寫說明：以抽象語言描述每個角色，不要寫入任何特定工具的代理設定、指令或 API 語法。將 `<...>` 佔位符替換為實際內容即可；每新增一個角色就新增一列。
> 分類說明：製造者角色負責產出結果；檢查者角色負責審查結果。同一 Loop 內產出任務與審查任務須指派給不同的 Sub_Agent_Role 實例（允許同型別不同實例）。
> 存取權限說明：唯讀角色僅能讀取與回報發現，不得修改程式碼；可寫角色可修改其職責範圍內的產物。

## 預設角色

下列四個預設角色可直接採用或依需要調整；Explorer 與 Reviewer 為唯讀角色，僅限讀取與回報，不得修改程式碼。

| 角色名稱 | 職責範圍 | 輸入 | 輸出 | 存取權限 | 製造者/檢查者 |
| --- | --- | --- | --- | --- | --- |
| Explorer | 探查程式碼與現況、彙整相關脈絡與發現 | `<待探查的問題或範圍>` | `<脈絡摘要與發現報告>` | 唯讀 | 檢查者 |
| Implementer | 依需求產出或修改程式碼與產物 | `<需求與 Explorer 的發現>` | `<實作變更>` | 可寫 | 製造者 |
| Tester | 撰寫並執行測試以驗證產物 | `<待驗證的實作與驗收條件>` | `<測試與測試結果>` | 可寫 | 製造者 |
| Reviewer | 審查產物是否符合 Verification_Condition 並回報 | `<待審查的產物>` | `<審查意見與核准/退回結論>` | 唯讀 | 檢查者 |

## 填寫檢查

- [ ] 每個角色皆已填寫角色名稱、職責範圍、輸入/輸出、存取權限與製造者或檢查者分類。
- [ ] 存取權限已明確標示為「唯讀」或「可寫」其中之一；Explorer 與 Reviewer 標示為唯讀。
- [ ] 每個角色已分類為「製造者」或「檢查者」其中之一。
- [ ] 若 Loop 同時含產出與審查任務，產出任務與審查任務已指派給不同的 Sub_Agent_Role 實例。
- [ ] 角色定義以抽象語言描述，未寫入任何工具專屬的代理設定、指令或 API 語法。
