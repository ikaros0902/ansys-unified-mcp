# LS-DYNA 單元屬性與截面定義指南 (`parts_and_sections.md`)

在 LS-DYNA 顯式分析中，`*PART` 卡片負責將幾何本體網格、截面屬性 (`*SECTION_*`) 與材料模型 (`*MAT_*`) 繫結。合理配置單元積分演算法是兼顧數值穩定性與求解效率的核心。

---

## 一、部件定義卡片 (`*PART`)

每個獨立零件透過 `PID` 標記，並指向唯一的截面編號 `SECID` 與材料編號 `MID`：

```text
*PART
$#                                                                         title
Drop_Specimen_Solid_Body
$#     pid     secid       mid     eosid      hgid      grav    adpopt      tmid
         1         1         1         0         1         0         0         0
```

### 關鍵欄位解析：
- **`pid`**：部件唯一識別編號（整數）。
- **`secid`**：對應之截面屬性編號，指向 `*SECTION_SOLID` 或 `*SECTION_SHELL`。
- **`mid`**：對應之材料編號，指向 `*MAT_*` 卡片。
- **`hgid`**：指定之沙漏控制編號（若設為 0，則承襲全域 `*CONTROL_HOURGLASS` 設定；若指定非零整數，則關聯特定 `*HOURGLASS` 卡片）。

---

## 二、實體單元截面 (`*SECTION_SOLID`)

實體單元廣泛應用於厚壁構件、本體外殼及複雜三維結構。

```text
*SECTION_SOLID
$#   secid    elform       aet
         1         1         0
```

### 實體單元積分格式 (`elform`) 選型矩陣：

| `elform` 編號 | 演算法名稱 | 物理特性與計算優缺點 | 推薦工程場景 |
| :---: | :--- | :--- | :--- |
| **`1`** | **單點減縮積分 (Const. Stress)** | 運算速度最快，能承受極大變形而不易畸變中斷；但存在零能變形模式（沙漏效應），必須搭配剛度型沙漏阻尼。 | 落摔分析推薦首選（佔 90% 工況，須監控沙漏能）。 |
| **`2`** | **全積分 8 節點實體 (Fully Integrated)** | 無沙漏模式；但在薄壁彎曲或金屬塑性不可壓縮流動時易產生「剪切自鎖 (Shear Locking)」，虛假誇大結構剛度。 | 塊狀厚實體、純受壓/拉結構；嚴禁單層薄壁使用。 |
| **`-1` / `-2`** | **全積分自鎖修正高階實體** | 有效緩解剪切自鎖與體積自鎖，計算精度高，但運算耗時約為單點積分單元的 2~4 倍。 | 應力集中區或對塑性變形精度極度敏感之局部區域。 |

## 三、薄殼單元截面 (`*SECTION_SHELL`)

針對鈑金、塑膠薄殼構件（厚度遠小於長寬），使用殼單元可大幅提升 CFL 臨界時間步長。

```text
*SECTION_SHELL
$#   secid    elform      shrf       nip     propt   qr/irid     icomp     setyp
         2         2      1.00         5         0         0         0         0
$#      t1        t2        t3        t4      nloc     marea      idof    edgset
     1.200     1.200     1.200     1.200     0.000     0.000     0.000         0
```

### 關鍵欄位解析：
1. **`elform=2` (Belytschko-Tsay 殼單元)**：LS-DYNA 預設的高效共旋殼單元，兼具速度與穩定性。
2. **`nip` (厚度方向積分點數)**：
   - 預設值為 2 點（僅適用線性彈性）。
   - **工程規範**：材料發生彈塑性降伏、非線性大彎曲時，**`nip` 必須設定 $\ge 5$**，方能正確捕捉截面厚度方向的降伏層演化。
3. **`t1 ~ t4`**：單元四個角點之厚度（等厚度部件四者填入相同數值）。

## 四、沙漏控制卡片 (`*HOURGLASS`)

當採用單點減縮積分單元（實體 `elform=1` 或殼單元 `elform=2`）時，必須啟用沙漏控制以抑制非物理網格震盪。

```text
*HOURGLASS
$#    hgid       ihq        qh        ib        q1        q2        qb        qw
         1         4      0.10         0      1.50     0.060      0.10      0.10
```

### 關鍵參數設定標準：
- **`ihq=4` (Flanagan-Belytschko 剛度阻尼形式)**：落摔衝擊推薦形式，以人工剛度對抗沙漏模式，穩定性優於黏性阻尼 (`ihq=1~3`)。
- **`qh` (沙漏係數)**：建議基準值為 `0.10`（工程合理範圍 `0.05 ~ 0.15`）。嚴禁隨意調大至 `> 0.20`，避免向系統引入過大虛假剛度。
