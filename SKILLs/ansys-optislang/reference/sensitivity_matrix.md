# optiSLang 敏感度分析與 TSI 篩選手冊 (`sensitivity_matrix.md`)

面對高維度工程參數問題，盲目建立代理模型會遭遇「維度災難 (Curse of Dimensionality)」。optiSLang 的全域敏感度分析（Global Sensitivity Analysis）透過方差分解，精準識別驅動輸出響應的主導參數。

---

## 一、相關係數 vs 總靈敏度指數 (TSI)

| 評估指標 | 數學本質 | 優勢 | 局限性與風險 |
| :--- | :--- | :--- | :--- |
| **Pearson 線性相關係數** | 線性共變異數比值 | 計算極速、直觀 | 僅能捕捉嚴格線性關係，對非線性關係無能為力。 |
| **Spearman 秩相關係數** | 數值等級單調相關 | 能捕捉非線性單調趨勢 | 若響應呈現對稱 U 型（非單調），數值接近 0 易誤判。 |
| **總靈敏度指數 (TSI / Sobol)** | 基於全域方差分解 (ANOVA) | **能捕捉主效應及所有高階非線性交互作用** | 依賴 MOP 代理模型擬合精度。 |

---

## 二、總靈敏度指數 (Total Sensitivity Index, TSI) 數學原理

輸出響應 $Y$ 的全域方差 $V(Y)$ 被分解為各單一參數及其交互項之貢獻：
$$V(Y) = \sum_{i} V_i + \sum_{i < j} V_{ij} + \dots + V_{1,2,\dots,k}$$

- **一階靈敏度指數 (First-order Index)**：$S_i = \frac{V_i}{V(Y)}$（參數 $X_i$ 單獨引起的方差佔比）。
- **總靈敏度指數 (Total Sensitivity Index, TSI)**：
  $$\text{TSI}_i = 1 - \frac{V_{\sim i}}{V(Y)}$$
  包含參數 $X_i$ 本身的主效應，以及 $X_i$ 與其他所有參數的全部交互效應之和。

## 三、變數降維篩選黃金準則

在進入 MOP 最終訓練與 Pareto 最佳化之前，必須依據 TSI 進行維度精簡：

```mermaid
flowchart TD
    A[輸出參數之 TSI 計算結果] --> B{TSI 數值分級}
    B -->|TSI >= 0.15| C[核心主導驅動變數
納入關鍵優化參數集合]
    B -->|0.05 <= TSI < 0.15| D[次要影響變數
視預算保留或設為區間中值]
    B -->|TSI < 0.05| E[非顯著雜訊變數 (< 5%)
直接凍結為常數 排除尋優]
```

### 降維效益：
1. **防禦維度災難**：將變數從 15 個縮減至 4~6 個關鍵變數，使後續最佳化收斂速度提升 10 倍以上。
2. **提升代理模型泛化能力**：消除無關輸入參數引入的隨機數值噪聲，大幅改善 MOP 預測係數 CoP。
