# LS-DYNA 質量縮放監控準則 (`mass_scaling_rules.md`)

顯式動力學依賴 CFL 條件決定臨界時間步長。當模型中存在極少數過小或畸變的網格時，求解器會被迫採用極微小步長，造成求解耗時失控。質量縮放 (Mass Scaling) 透過給高頻單元人為注入虛擬質量來拉長步長，但**濫用質量縮放會扭曲衝擊慣性力**。

---

## 一、CFL 條件與臨界步長原理

實體單元的臨界時間步長公式為：
$$\Delta t_{\text{crit}} = \frac{L_{\text{char}}}{c} = \frac{L_{\text{char}}}{\sqrt{E / \rho}}$$
- 若將時間步長強制固定在 $\Delta t_{\text{target}}$，求解器必須調整密度：
$$\rho_{\text{virtual}} = E \cdot \left( \frac{\Delta t_{\text{target}}}{L_{\text{char}}} \right)^2$$
這意味著單元尺寸越小，被強加的虛擬質量呈二次方急劇暴增！

---

## 二、*CONTROL_TIMESTEP 卡片中的 DT2MS 規則

```text
*CONTROL_TIMESTEP
$#  dtinit    tssfac      isdo    tslimt     dt2ms      lctm     erode     ms1st
       0.0      0.90         0       0.0 -1.00e-07         0         0         0
```

### `DT2MS` 的物理意義：
- **`DT2MS < 0` (負值，強烈推薦)**：**選擇性質量縮放 (Selective Mass Scaling)**。
  - 求解器**僅針對**時間步長小於 $|DT2MS|$ 的畸變/小單元添加質量，將其步長提升至 $|DT2MS|$。步長大於該值的正常單元完全不受影響。
- **`DT2MS > 0` (正值，嚴禁使用)**：全域平移質量縮放，會無差別強行改變所有單元質量，徹底破壞動態慣性。

## 三、質量縮放百分比三大監控法則

在 LS-DYNA 求解輸出 (`d3hsp` 與終端日誌) 中，隨時統計 `Added Mass Percentage`：
$$\text{Added Mass Ratio} = \frac{\Delta M}{M_{\text{initial}}} \times 100\%$$

| 質量增加比例區間 | 工程判定等級 | 處置行動方針 |
| :---: | :---: | :--- |
| **$< 1.0\%$** | **綠燈 (極佳)** | 慣性效應近乎無失真，衝擊峰值加速度與結構塑性變形高度可信。 |
| **$1.0\% \sim 2.0\%$** | **黃燈 (合格邊界)** | 工程允收上限。需確認增加質量是否分散在非衝擊主承載區。 |
| **$2.0\% \sim 5.0\%$** | **橘燈 (警示嚴查)** | **必須調閱新增質量分佈**。若質量集中在落摔撞擊角或大變形鉸鏈處，結果無效。 |
| **$> 5.0\%$** | **紅線 (嚴格禁行)** | **嚴禁交付結果！** 人為虛擬慣性嚴重壓低結構加速度頻率響應，徹底失真。 |

## 四、質心漂移與慣性矩檢核

除了全域總質量增加率外，還必須檢核質心 (Center of Gravity, CG) 的位置變化：
1. **質心偏移量**：
   $$\Delta \vec{r}_{\text{CG}} = |\vec{r}_{\text{CG, final}} - \vec{r}_{\text{CG, initial}}| < 0.1\% \cdot L_{\text{total}}$$
2. 若虛擬質量過度集中在某一角落，會產生虛假的偏心力矩，導致落摔體在空中有非物理的偏轉或旋轉翻滾。
3. **根治對策**：透過預處理網格清理，消除倒角處的退化微小四面體網格，切勿企圖依賴調大 `DT2MS` 來強行加速。
