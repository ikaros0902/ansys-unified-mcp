# LS-DYNA 接觸卡片設定指南 (`contacts.md`)

在顯式動力學落摔衝擊中，接觸邊界是最強烈的非線性來源。LS-DYNA 主要基於 Penalty（懲罰函數法）處理接觸界面。

---

## 二、SOFT 接觸剛度演算核心選型

`soft` 參數決定接觸介面法向彈簧剛度的計算準則，直接左右穿透程度與求解穩定性：

| `soft` 選項 | 演算法定義 | 適用工程場景 | 注意事項 |
| :---: | :--- | :--- | :--- |
| **`0`** | **標準 Penalty 剛度法** | 適用於材料剛度相近之金屬對金屬接觸。以單元體積模數與截面幾何計算剛度。 | 當硬金屬與發泡/橡膠接觸時，預設剛度偏小，極易造成嚴重穿透。 |
| **`1`** | **節點質量剛度法 (Soft Constraint)** | 依據接觸節點質量與臨界時間步長動態推算剛度，能有效匹配懸殊剛度界面。 | **異質材料接觸首選（如鋼板碰撞塑膠墊、落地碰撞）**。 |
| **`2`** | **線段-線段接觸 (Segment-based Contact)** | 以線段取代傳統節點-面接觸，自動處理尖角、邊緣對邊緣以及自摺疊接觸。 | 複雜幾何碰撞、自接觸 (`AUTOMATIC_SINGLE_SURFACE`) 強烈推薦。 |

## 三、關鍵參數調校清單

1. **摩擦係數 (`fs`, `fd`)**：
   - `fs`：靜摩擦係數（金屬-地面通常設 `0.20 ~ 0.40`）。
   - `fd`：動摩擦係數（建議 `fd <= fs`）。
2. **黏滯阻尼係數 (`vdc`)**：
   - 接觸法向黏滯阻尼（百分比，推薦取 `20.0`），可有效衰減碰撞接觸產生的局部高頻非物理數值噪聲。
3. **厚度偏移 (`sst`, `mst`)**：
   - 實體單元預設為 0；殼單元預設接觸厚度為其物理厚度。
4. **初始穿透容差處置 (`ignore` / `depth`)**：
   - 建模網格若在初始時刻存在微量相交，設定 `ignore=1` 避免在 $t=0$ 產生巨大排斥力引發爆炸。
