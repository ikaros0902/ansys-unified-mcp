# Automation_Trigger 定義樣板

> 用途：定義一個 Loop 的自動化觸發機制，記錄其觸發類型、觸發條件與執行頻率。
> 建議存放位置：專案內 Loop 設計文件旁（例如 `loops/<loop-name>/automation-trigger.md`）。
> 填寫說明：以抽象語言描述觸發時機，不要寫入任何特定工具的排程語法、指令或設定欄位。將 `<...>` 佔位符替換為實際內容即可。

## 基本資訊

| 欄位 | 內容 |
| --- | --- |
| Loop 名稱 | `<此觸發所屬的 Loop 名稱>` |

## 觸發定義

| 欄位 | 說明 | 填寫內容 |
| --- | --- | --- |
| 觸發類型 | 屬於定時觸發或事件觸發（擇一） | `<定時觸發 / 事件觸發>` |
| 觸發條件 | 觸發的具體條件描述：定時觸發填時間規則；事件觸發填事件來源與事件類型 | `<例如：每個工作日早上 / 主線分支有新推送時>` |
| 執行頻率 | 預期的執行頻率，建議含頻率單位；事件觸發亦須估計 | `<例如：每日一次 / 每次事件發生時，估計每日約 5–10 次>` |

## 填寫檢查

- [ ] 觸發類型已明確標示為「定時觸發」或「事件觸發」其中之一。
- [ ] 觸發條件以抽象語言描述，未寫入任何工具專屬的排程語法或指令。
- [ ] 執行頻率已填寫並含頻率單位（供成本與風險控管評估使用）。
