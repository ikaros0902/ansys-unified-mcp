# Cost & Risk Control 定義樣板

> 用途：記錄一個 Loop 的成本與風險控管設定，包含各 Sub_Agent_Role 的模型分層、執行頻率、成本上限、超限處理方式與觸發方式，供自動重複執行時控管執行次數與費用。
> 建議存放位置：專案內 Loop 設計文件旁（例如 `loops/<loop-name>/cost-risk-control.md`）。
> 填寫說明：以抽象語言描述控管設定，不要寫入任何特定工具的模型名稱、排程語法、指令或設定欄位。將 `<...>` 佔位符替換為實際內容即可。
> 模型分層說明：依 Sub_Agent_Role 的任務性質選擇模型量級——輕量模型（低成本、簡單分類與彙整）、主力模型（一般產出與修改）、強推理模型（高難度推理與審查）。
> 觸發建議：優先採用事件觸發而非固定高頻率排程，以降低無變化時的空轉執行；執行頻率建議以低頻率起步，再依產出品質調整。

| 欄位 | 說明 | 填寫內容 |

## 填寫檢查

- [ ] 每個 Sub_Agent_Role 皆已標示對應的模型量級為「輕量」「主力」或「強推理」其中之一。
- [ ] 執行頻率已填寫並含頻率單位。
- [ ] 若已設定成本或 Token 用量上限，已同時記錄上限數值與超限處理方式兩者，未僅記錄其中一項。
- [ ] 觸發方式已明確標示為「定時觸發」或「事件觸發」其中之一。
- [ ] 控管設定以抽象語言描述，未寫入任何工具專屬的模型名稱、排程語法或指令。
