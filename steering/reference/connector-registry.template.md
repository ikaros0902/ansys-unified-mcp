# Connector 清單樣板

> 用途：記錄一個或多個 Loop 所使用的 Connector，包含其名稱、用途、存取範圍與所屬 Loop，供接入外部系統時追溯與控管。
> 建議存放位置：專案內共用文件處（例如 `connectors/registry.md`），供各 Loop 引用。
> 填寫說明：以抽象語言描述每個 Connector，不要寫入任何特定工具的連線設定、指令或 API 語法。將 `<...>` 佔位符替換為實際內容即可；每新增一個 Connector 就新增一列。

## Connector 清單

| 名稱 | 用途 | 存取範圍 | 所屬 Loop |
| --- | --- | --- | --- |
| `<Connector 識別名>` | `<存取目的，例如：讀取問題追蹤系統的工單>` | `<可讀/可寫的資源範圍，例如：唯讀某專案的 issue 清單>` | `<使用此 Connector 的 Loop 名稱>` |

## 填寫檢查

- [ ] 每個 Connector 皆已填寫名稱、用途、存取範圍與所屬 Loop 四個欄位。
- [ ] 存取範圍已明確標示可讀與可寫的資源界線（供安全與成本風控評估使用）。
- [ ] 若使用非 MCP 的 Connector 機制，已同時記錄其能力清單與存取範圍兩者，未僅記錄其中一項。
- [ ] 清單內容以抽象語言描述，未寫入任何工具專屬的連線設定、指令或 API 語法。
