CORE ARCHITECTURE

薄腳本執行核心 (Thin Runner)

本系統不逐一綁死高階 API，核心原語直接將原生腳本字串投遞至目標程式執行。無論 ANSYS 版本升級至 2024、2025 或 2026，底層語法均具備高度向後相容性。

ISOLATION STRATEGY

進程內多工作區隔離 (方案 D+A)

捨棄笨重的作業系統級多進程切分，改採同進程內動態 Workspace 鍵與可見性過濾器。既避免大量工具塞爆 AI 的對話 Context，又完整保留幾何到最佳化的跨領域連鎖運算能力。

QUALITY GATE

636 項自動化驗收防線

內建對抗性測試與 AST 靜態掃描，確保所有 155 個工具皆符合回傳信封契約（dict Envelope）。收斂後的五大乾淨目錄杜絕檔案污染，保障企業生產環境穩定度。
