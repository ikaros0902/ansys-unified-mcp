FUNCTIONAL AGENT & SESSION SKILLS · WORKFLOW TOPOLOGY

職能代理分工與循序會話技能架構

參考 Ansys 官方工作範例：由頂層代理分發需求至領域代理，展開循序執行的 Session 技能鏈，並透過獨立審查者與工程師簽核完成交付。

TIER 1 · DISPATCH & SPECIALIZATION

頂層路由與專業領域代理

依據模擬工況將任務精準交由專屬領域處理：

  • 頂層路由 (Top-Level Agent)：解析工程師輸入，判斷屬於結構、熱傳或流體問題。
  • 領域代理 (Workflow Agents)：結構代理專精剛強度與落摔；熱傳代理專精散熱；流體代理專精流場與壓降。

TIER 2 · SEQUENTIAL SKILLS

循序執行的 Session 技能鏈

將複雜 CAE 流程拆解為 5 個受控的標準步驟：

  • 幾何前處理：修復破面、特徵簡化與抽取流體域。
  • 網格劃分：依據物理場自動生成網格並檢驗雅可比值。
  • 求解與後處理：設定邊界條件求解，並透過 DPF 提取關鍵指標。

TIER 3 · GOVERNANCE & SIGN-OFF

製造檢查分離與工程師簽核

落實工程誠信與可客觀驗證的防護機制：

  • 獨立審查 (Reviewer Agent)：負責求解的代理不得自己審核，由獨立審查者檢查收斂與質量比。
  • 責任歸屬於人 (Human Sign-Off)：AI 整理出數據後，最終仍由工程師簽核背書。
