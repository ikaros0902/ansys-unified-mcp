## 使用方式與限制

- `sources.csv` 列出已索引項目及清冊中的新增來源，包含分類、版本、品質、來源網址及本機路徑；`正文已索引` 表示正文已進入 SQLite；`正文待索引` 表示正文存在但仍待索引；`未索引：attachment/template` 表示附件或範本不作全文正文；`品質待查` 表示內容仍需核對。相同文件可能有不同格式或版本，筆數不是唯一文件數。
- `topics.csv` 追蹤主題的整理狀態：`planned` 尚無摘要；`draft` 已有首輪摘要但仍待指定版本官方原文逐項核對；`complete` 僅用於來源與版本已核實的主題。`source_refs` 以分號分隔，可指向庫內相對路徑或 `sources.csv#document_id`；`source_online_not_cached`／`source_online_partial` 表示官方遠端來源已找到，但未快取成可搜尋正文。
- Markdown 頁面中的來源路徑以本機工作區為準。分享給團隊前須確認原始文件與衍生內容的使用限制。
- 原始 PDF、HTML、圖片及 REA 萃取產物不在此複製或修改。
- `optiSLang/unknown/manuals` 中兩份 `lsopt_2026R1_*.pdf` 是 LS-OPT 2026 R1，已標為 `general`，不納入 optiSLang 文件搜尋；請勿據此推定 optiSLang 手冊已齊備。
