EDITORIAL ARCHITECTURE · DIAGRAM DESIGN

ANSYS Unified MCP 現行系統架構拓撲

展示 FastMCP 扁平信封契約閘道、前置物理安全閘門、沙盒隔離執行與 DPF 無頭後處理之五層式穩固拓撲架構。

TIER 1 · GATEWAY & SAFETY

介面規範與前置檢查

在求解前檢查關鍵物理量，避免無效運算或數值發散：

  • 回傳格式統一：工具層一律回傳字典結構（包含 ok 欄位），方便程式化斷言。
  • 物理門檻防護：三向有效模態質量比需達 90%，確認單位制與割線 CTE。
  • 自愈引導：檢查未通過時退回請求，並附上具體修改方向。

TIER 2 · EXECUTION & SENTINEL

沙盒隔離與運算監控

隔離每次模擬的輸入與輸出檔案，維護連線穩定：

  • 獨立沙盒目錄：每次計算建立獨立 jobs/{timestamp}_{type}/ 資料夾，原始 CAD 設為唯讀。
  • 連線逾時處理：檢測 gRPC 連線狀態，調用逾時即主動剔除異常連線。
  • 進度監看：背景讀取求解日誌，當沙漏能超過 5% 時主動中止，節省運算時間。

TIER 3 · DPF & SSOT SKILLS

後處理提取與技能共用

待計算完成後再讀取結果，並共用技能手冊：

  • 避免檔案鎖衝突：求解器確認完成後，複製 .rst 至沙盒再交由 DPF 提取雲圖。
  • 標準成果輸出：自動整理 summary.json 關鍵數值、白底雲圖與 overview.html 報告。
  • 目錄連接點共用：專案以 SKILLs/ 為主，透過 NTFS Junction 映射至各 IDE 目錄。
