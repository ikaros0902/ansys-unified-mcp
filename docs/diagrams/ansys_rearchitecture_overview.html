ANSYS MCP REARCHITECTURE

CAE-Agent-Hub 垂直切片架構

DEVELOPER VIEW (開發視角)

卡匣式垂直切片 (Decoupling)

解決了過去 tools 與 drivers 程式碼互相依賴的「大鍋炒」痛點。

  • 通訊分離：底層 File Queue 與 Socket 統一收斂至 bridges/ 層，不再與業務邏輯綁定。
  • 獨立卡匣：Mechanical、Fluent 等產品邏輯完全獨立於 products/，增刪功能互不干擾。
  • 易於測試：Mocking 更直覺，單元測試覆蓋率與除錯效率顯著提升。

EXECUTIVE VIEW (管理視角)

降低維護成本與容錯防線

從單體實驗腳本，轉型為具備防禦機制的高可維護企業級自動化平台。

  • 零浪費防呆：Gatekeeper 層會在呼叫耗時的 ANSYS 求解器前，自動攔截參數錯誤與單位衝突，大幅節省無效運算算力。
  • 平滑擴充：外掛式的產品架構，未來導入新模擬軟體可無痛熱插拔。
  • 降低交接成本：底層標準化降低了新進工程師理解架構的門檻。
